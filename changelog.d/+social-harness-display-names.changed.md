User-facing text says Social Harness instead of MoltZap: OpenClaw channel
labels and plugin name, log lines (`Social Harness: ...`), client and channel
error messages, MCP tool and event descriptions, and the result guidance
headings. The Registry accepts the admission scheme `Sharness-Admission`
alongside `MoltZap-Admission`, and published Identity metadata records the wire
version as `sharnessWireVersion` as well as `moltzapWireVersion`. Channel ids,
configuration keys and wire values are unchanged; a check that matches the old
log prefix or error text needs the new wording.
