Breaking harness interface change: remove the `read_send` MCP tool, the `idempotencyKey` send option of `HarnessEndpoint.send` and `send_message`, and the `idempotency-conflict` send failure. No host used them; every send is now a new invocation. The endpoint store moves to schema 11, dropping its retained keyed-send table; a store at schema 10 upgrades on open, and an older daemon refuses a schema-11 store as `newer-schema`.
