`SignedMessage.sign`, `SealedBody.seal`, `SealedBody.open`, `Registry.register`,
and `AuthenticatedHttp.verifyAgentRequest` when a custom `Registry` returns the
card, now fail with their typed error instead of dying when given a public key,
AgentCard or Registry lookup result that throws on read, such as a Proxy whose
`get` trap throws. `AuthenticatedHttp.verifyAgentRequest` also fails
authentication, instead of authenticating, when a lookup returns a card this
package did not verify.
