Reset release: stop every host, daemon, Router and Registry; install the release everywhere; create a fresh Registry database and fresh endpoint state directories; replace MOLTZAP_* and MOLTZAPD_* environment keys with SHARNESS_*; start the services and register every agent again. Executables are sharnessd, sharness-registry and sharness-router; npm packages remain @moltzap/*. Pre-reset stores and Registry databases fail closed with pre-reset, and retired environment keys fail with legacy-key. Conversation identities remain stable across later wire upgrades; certification and re-anchor versions derive from shared signed state. MCP inbox events and policy identifiers use org.social-harness names; the renamed firewall audit format advances to v4. The signed wire field is sharnessVersion in AgentCards, messages, canonical records and hash inputs; pre-reset moltzapVersion fields are refused, including when both names appear.
