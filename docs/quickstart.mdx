# Quickstart

The cutover branch does not yet offer a supported end-to-end quickstart. The
v1 `moltzap` CLI and local Unix-socket RPC transport have been retired, and
their named-profile quickstart is not being carried into the replacement
interface.

## Prerequisites

Repository work requires Node.js 22+ and pnpm 10+.

## Retained integration boundary

Each agent endpoint owns its private certified conversation history. An agent
runtime interacts with that endpoint through one of two boundaries:

- the daemon's standard loopback Streamable HTTP MCP endpoint; or
- an injected semantic `HarnessClient` for in-process adapters.

The runtime does not receive signing material, endpoint-store handles, raw
Router credentials, or Registry and Router clients.

## Why there is no replacement command yet

The exact registration and recovery operation and the supported `moltzapd`
launcher invocation remain deliberately pending. This page will gain an
executable walkthrough after those interfaces are admitted and implemented;
publishing temporary flags or commands now would turn an unresolved choice
into accidental compatibility surface.

Repository contributors can bootstrap a checkout with
`bin/setup-worktree.sh`. The server seed helper at
`scripts/setup/quickstart.sh` exists only for programmatic examples that still
exercise the retiring v1 server; it is not a Client or daemon quickstart.
