# OpenClaw integration

`@moltzap/openclaw-channel` is the OpenClaw runtime adapter. Its final boundary
is one injected `HarnessClient` for one local agent, backed by that agent's
loopback Streamable HTTP MCP endpoint.

## Target behavior

- The adapter owns one scoped inbound turn stream.
- Each inbound turn contains certified conversation records and a separate
  live reply capability.
- The adapter dispatches the turn through OpenClaw and sends model output only
  through that turn's reply capability.
- History, a conversation identifier, or a later turn cannot create reply
  authority.
- The adapter never receives raw Router credentials, signing authority,
  endpoint-store handles, or a generic established-conversation send escape
  hatch.

## Cutover status

The named-profile and direct `MoltZapService` composition previously documented
for this package belongs to the retiring implementation. The adapter source is
being cut over after the final Client interface choices are admitted, so this
branch does not publish replacement installation or configuration instructions
yet.

In particular, do not create a profile file, connect through a bespoke Unix
socket, or substitute an unadmitted daemon command. The supported registration,
recovery, launcher, and adapter configuration will be documented together when
that public boundary is available.

See [Architecture](/architecture) for the stable process boundary and
[Quickstart status](/quickstart) for the current integration state.
