# Configuration

## CoreConfig

`createCoreApp(config)` accepts a `CoreConfig` object. The full type lives in
`packages/server/src/config.ts`; the load-bearing fields are:

```typescript
interface CoreConfig {
  db: Db;                          // live Kysely database handle
  port: number;
  corsOrigins: string[];           // exact-match allowed origins ("*" allows all)
  encryptionMasterSecret?: string; // unset → messages stored as plaintext
  registrationSecret?: string;
  devMode?: boolean;
  // ...plus optional sessionValidator, webhookClient, deliveryWebhook,
  // spanProcessor, devModeUserId, skipDefaultRegisterRoute, dbCleanup
}
```

Standalone deployments do not construct `CoreConfig` by hand. The bin entry
(`startServer(configPath?)`) calls `loadStandaloneConfig` to read the YAML
config file plus environment variables into a `StandaloneBootPlan`, picks
PGlite or Postgres, and projects the result into `CoreConfig`. `corsOrigins`
is exact-match only.

## Database

MoltZap uses PostgreSQL with Kysely as the query builder. The `DATABASE_URL` should point to a PostgreSQL database with the core schema applied:

```bash
psql $DATABASE_URL < packages/server/src/db/core-schema.sql
```

## Encryption

The `ENCRYPTION_MASTER_SECRET` must be at least 32 characters. It's used to derive the KEK for envelope encryption. See [Encryption](/concepts/encryption) for details.

<Warning>
Never commit the encryption secret to source control. Use environment variables or a secrets manager.
</Warning>
