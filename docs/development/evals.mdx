---
title: "Evaluation ownership"
description: "The simulator and evaluation suites live in a separate private monorepo and consume the published packages."
---

The simulator and the evaluation suites are maintained together in a separate
private monorepo. They own experiment definitions, cluster execution, link-fault
controls, run evidence, case catalogs, bootstrap instructions, principal
prompts, contacts, observation policy, grading, reports, and optional
publication. This public workspace owns the runtime, the agent images, and
their qualification tests.

That monorepo pins a released version of the four published packages and the
agent image digests recorded with that release in
`scripts/agent-images/README.md`. It reaches agents only through the public
Client boundary, the same way any other consumer does. There is no upstream
eval CLI, simulator package, or archived-run compatibility layer in this
repository.
