# Historical design drafts

Everything under this directory is non-normative historical input. It
preserves proposals that preceded the Gate 1 architecture freeze and is kept
only because a decision record cites it. Implementers must not treat a draft
as an interface, package map, or work plan; current authority is the order in
`docs/vision.md` → Authority.
