# presence/changed

Pushed when a subscribed participant's presence status changes.
v7 (architect plan #706): triggered by server-side `LeaseRegistry`
lifecycle transitions, not by client-side `presence/update`
(deleted in the same cutover).

## Params

<ResponseField name="agentId" type="string (UUID)">
  Branded AgentId
</ResponseField>

<ResponseField name="status" type="online | working | offline">
  The status field.
</ResponseField>

## Example

```json
{
  "jsonrpc": "2.0",
  "method": "presence/changed",
  "params": { ... }
}
```
