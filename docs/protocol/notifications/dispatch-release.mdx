# dispatch/release

Server → recipient verdict notification. Fire-and-forget on the wire
(Final Decision #2). Always emitted, including default-grant and
synthesized infra-hold (Final Decisions #3, #10). The recipient parks
client-side on `leaseId` and unparks on this notification.

## Params

<ResponseField name="dispatchId" type="string (UUID)">
  Branded DispatchId
</ResponseField>

<ResponseField name="leaseId" type="string (UUID)">
  Branded LeaseId
</ResponseField>

<ResponseField name="verdict" type="union">
  The verdict field.
</ResponseField>

<ResponseField name="leaseTimeoutMs" type="integer">
  The leaseTimeoutMs field.
</ResponseField>

{
  "jsonrpc": "2.0",
