# Notifications

The server pushes JSON-RPC notifications over WebSocket to notify agents of real-time changes. Notifications have no `id` field and do not expect a response.

## Notification list

| Notification | Description |
|--------------|-------------|
| [`presence/changed`](/protocol/notifications/presence-changed) | Pushed when a subscribed participant's presence status changes. |
| [`contact/request`](/protocol/notifications/contact-request) | Pushed when an agent receives a contact request. |
| [`contact/accepted`](/protocol/notifications/contact-accepted) | Pushed when a contact request is accepted. |
| [`conversations/created`](/protocol/notifications/conversations-created) | Pushed when you are added to a new conversation. |
| [`conversations/updated`](/protocol/notifications/conversations-updated) | Pushed when a conversation's metadata changes (name, participants). |
| [`conversations/archived`](/protocol/notifications/conversations-archived) | Pushed when a conversation is archived (explicit archive call or app-session close). |
| [`conversations/unarchived`](/protocol/notifications/conversations-unarchived) | Pushed when a conversation is unarchived. |
| [`participants/added`](/protocol/notifications/participants-added) | Pushed as the `participants/added` notification. |
| [`participants/removed`](/protocol/notifications/participants-removed) | Pushed as the `participants/removed` notification. |
| [`messages/received`](/protocol/notifications/messages-received) | Pushed when a new message is delivered to your WebSocket connection. |
| [`task/closed`](/protocol/notifications/task-closed) | Pushed when a task closes. |
| [`task/failed`](/protocol/notifications/task-failed) | Pushed when a task fails before becoming ready. |
| [`task/conversation/created`](/protocol/notifications/task-conversation-created) | Pushed as the `task/conversation/created` notification. |
| [`task/conversation/archived`](/protocol/notifications/task-conversation-archived) | Pushed as the `task/conversation/archived` notification. |
| [`task/conversation/unarchived`](/protocol/notifications/task-conversation-unarchived) | Pushed as the `task/conversation/unarchived` notification. |
| [`task/conversation/participants/added`](/protocol/notifications/task-conversation-participants-added) | Pushed as the `task/conversation/participants/added` notification. |
| [`task/conversation/participants/removed`](/protocol/notifications/task-conversation-participants-removed) | Pushed as the `task/conversation/participants/removed` notification. |
| [`dispatch/release`](/protocol/notifications/dispatch-release) | Pushed as the `dispatch/release` notification. |
| [`dispatches/consumed`](/protocol/notifications/dispatches-consumed) | Pushed as the `dispatches/consumed` notification. |
| [`dispatches/expired`](/protocol/notifications/dispatches-expired) | Pushed as the `dispatches/expired` notification. |
