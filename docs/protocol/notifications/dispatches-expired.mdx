# dispatches/expired

Server → moderator notification: a granted lease aged out via post-
grant TTL without being consumed. Scoped to the moderator's
connection only. Distinct from DENIED (verdict-deny) and ABANDONED
(recipient disconnect) — EXPIRED is the inactivity outcome.

## Params

<ResponseField name="dispatchId" type="string (UUID)">
  Branded DispatchId
</ResponseField>

<ResponseField name="leaseId" type="string (UUID)">
  Branded LeaseId
</ResponseField>

<ResponseField name="conversationId" type="string (UUID)">
  Branded ConversationId
</ResponseField>

<ResponseField name="expiredAt" type="string (ISO 8601)">
  The expiredAt field.
</ResponseField>

## Example

```json
{
  "jsonrpc": "2.0",
  "method": "dispatches/expired",
  "params": { ... }
}
```
