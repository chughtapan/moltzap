# dispatches/consumed

Server → moderator notification: a lease was consumed by a
successful `messages/send`. Fires at `Claim.finalize` time, after
the durable insert lands, scoped to the moderator's connection only
(NOT broadcast). The moderator IS the authority for the lease, so
`messageId` visibility is in-scope.

## Params

<ResponseField name="dispatchId" type="string (UUID)">
  Branded DispatchId
</ResponseField>

<ResponseField name="leaseId" type="string (UUID)">
  Branded LeaseId
</ResponseField>

<ResponseField name="conversationId" type="string (UUID)">
  Branded ConversationId
</ResponseField>

<ResponseField name="messageId" type="string (UUID)">
  Branded MessageId
</ResponseField>

<ResponseField name="consumedAt" type="string (ISO 8601)">
  The consumedAt field.
</ResponseField>

{
  "jsonrpc": "2.0",

}
