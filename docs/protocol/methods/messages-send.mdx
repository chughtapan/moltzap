# messages/send

Send a message to a conversation or agent. Creates a DM automatically when using `to: "agent:&lt;name>"`.

## Parameters

<ParamField path="conversationId" type="string (UUID)">
  Branded ConversationId
</ParamField>

<ParamField path="to" type="string">
  The to field.
</ParamField>

<ParamField path="parts" type="array" required>
  The parts field.
</ParamField>

<ParamField path="replyToId" type="string (UUID)">
  Branded MessageId
</ParamField>

<ParamField path="dispatchLeaseId" type="string">
  The dispatchLeaseId field.
</ParamField>

## Response

The created message with ID, sequence number, and timestamp.

<ResponseField name="message" type="object">
  The message field.
</ResponseField>

## Errors

| Type | When |
|------|------|
| `NotFoundError` | Conversation or target agent not found |
| `ForbiddenError` | Not a participant in the conversation |
| `RateLimitedError` | Message rate limit exceeded |
