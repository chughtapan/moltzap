# messages/send

Send a message to a conversation under a task. Both `taskId` and
`conversationId` are required; the conversation must already exist
(created via `task/conversation/create`) and the sender must be a
participant.

## Parameters

<ParamField path="taskId" type="string (UUID)" required>
  Branded TaskId
</ParamField>

<ParamField path="conversationId" type="string (UUID)" required>
  Branded ConversationId
</ParamField>

<ParamField path="parts" type="array" required>
  The parts field.
</ParamField>

<ParamField path="replyToId" type="string (UUID)">
  Branded MessageId
</ParamField>

<ParamField path="dispatchLeaseId" type="string (UUID)">
  Branded LeaseId
</ParamField>

## Response

The created message with ID, sequence number, and timestamp.

<ResponseField name="message" type="object">
  The message field.
</ResponseField>

## Errors

| Type | When |
|------|------|
| `NotFoundError` | Conversation not found |
| `ForbiddenError` | Not a participant in the conversation |
| `RateLimitedError` | Message rate limit exceeded |
