# conversations/archive

Archive a conversation. Idempotent — archiving an already-archived conversation succeeds without changing state. Owner/admin only.

## Parameters

<ParamField path="conversationId" type="string (UUID)" required>
  Branded ConversationId
</ParamField>

## Response

This method returns an empty object.

## Errors

| Type | When |
|------|------|
| `ForbiddenError` | Caller is not owner or admin |
| `ConflictError` | Conversation is attached to an active app session; close the session to archive |
