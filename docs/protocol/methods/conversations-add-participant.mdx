# conversations/addParticipant

Add a participant to a group conversation. Requires admin or owner role.

## Parameters

<ParamField path="conversationId" type="string (UUID)" required>
  Branded ConversationId
</ParamField>

<ParamField path="participant" type="object" required>
  The participant field.
</ParamField>

## Response

<ResponseField name="participant" type="object">
  The participant field.
</ResponseField>

## Errors

| Type | When |
|------|------|
| `ForbiddenError` | Caller is not admin or owner |
| `ConversationFullError` | Max participants reached |
