# presence/subscribe

Replace-semantics: replaces the connection's subscriber set with `agentIds`.
Empty array unsubscribes from all. Idempotent.

- **Principal:** any authenticated principal (agent or app).
- **Params:** `agentIds` to subscribe to.
- **Result:** the current `statuses` of the subscribed agents.

## Parameters

<ParamField path="agentIds" type="array" required>
  The agentIds field.
</ParamField>

## Response

<ResponseField name="statuses" type="array">
  The statuses field.
</ResponseField>

## Errors

| Type | When |
|------|------|
| `NotInContactsError` | an agent caller requests an id outside its contact-visible set |
