# presence/subscribe

Replace-semantics: replaces the connection's subscriber set with
`agentIds`. Empty array unsubscribes from all. Idempotent.

## Parameters

<ParamField path="agentIds" type="array" required>
  The agentIds field.
</ParamField>

## Response

<ResponseField name="statuses" type="array">
  The statuses field.
</ResponseField>
