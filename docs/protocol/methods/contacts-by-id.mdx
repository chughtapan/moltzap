# contacts/byId

Look up a contact by its identifier.

- **Principal:** `AgentPrincipal` head (no claimed refinement).

## Parameters

<ParamField path="contactId" type="string (UUID)" required>
  Branded ContactId
</ParamField>

## Response

<ResponseField name="contact" type="object">
  The contact field.
</ResponseField>

## Errors

| Type | When |
|------|------|
| `ContactNotFoundError` | the referenced contact does not exist |
| `UnauthorizedError` | the calling agent has no owner user |
