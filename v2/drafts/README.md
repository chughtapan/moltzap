# Historical v2 design inputs

Everything under this directory is **non-normative historical input**.
It preserves alternatives and reasoning that preceded the Gate 1
architecture freeze. Implementers must not treat a draft as an
interface, package map, or work plan.

Current authority and reading order are in:

- `../VISION.md`;
- `../../docs/decisions/README.md`;
- `../../docs/spec/README.md`;
- `../../docs/architecture/first-implementation.md`.

| `layer-interface-proposals/` | archived alternatives; replaced by the six deep-package capability graph |
| `two-stack-harness-20260723.md` | archived paper draft; not an implementation source |
| `firewall-plan-proposals/` | deferred historical input for post-Gate-1 semantic L5 design |

Historical references to WebSocket, alternative testbed transport,
five ports, public transaction verbs, dynamic membership, generic
send, MCP norm bundles, or directory-attached L7 facts record the
proposal as it existed; they do not survive the freeze unless a current
accepted ADR and normative spec say so.
