# Built-in firewall rules

`index.ts` exposes the registrations policy composition selects.
`builtin.ts` supplies credential, plain-language, acknowledgement and
allowed-sender policies. `collective-norms.ts` combines code and English rules
for collective participation. It reads the Client release from `../../release/`
for revision and provenance bytes. `outcome.ts` holds shared rule results
and digest construction.

See the [message-policy specification](https://github.com/social-harness/moltzap/blob/main/docs/spec/harness/message-policy.md#message-policy-file).
